<Steps>
<Step>

### Download and install

Download the latest Launchpad release from your [Library](/account/library), then:

```bash
unzip launchpad-*.zip -d my-site && cd my-site
pnpm install
pnpm dev
```

</Step>
<Step>

### Replace the sample content

Edit copy in `messages/en.json` and `messages/de.json`. See [Editing content](/docs/launchpad/editing-content).

</Step>
<Step>

### Deploy

Follow [Deploy](/docs/launchpad/deploy).

</Step>
</Steps>

<Callout>Templates include a license key for support and the verified-owner Discord; activation is optional.</Callout>
