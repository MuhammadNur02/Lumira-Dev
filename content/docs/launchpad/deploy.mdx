---
title: Deploy
description: Ship Launchpad to Vercel or any Node.js host.
product: launchpad
since: 1.0.0
---

1. Push the project to a Git repository and import it in Vercel.
2. Keep the default build command (`pnpm build`) and output settings.
3. Add your domain in the project settings.

```bash
pnpm build && pnpm start   # any Node.js 24 host
```
