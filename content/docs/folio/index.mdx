<Steps>
<Step>

### Download and install

Download the latest Folio release from your [Library](/account/library), then:

```bash
unzip folio-*.zip -d my-site && cd my-site
pnpm install
pnpm dev
```

</Step>
<Step>

### Replace the sample content

Edit case studies in `content/work/*.mdx`. See [Editing content](/docs/folio/editing-content).

</Step>
<Step>

### Deploy

Follow [Deploy](/docs/folio/deploy).

</Step>
</Steps>

<Callout>Templates include a license key for support and the verified-owner Discord; activation is optional.</Callout>
