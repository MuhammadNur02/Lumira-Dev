---
title: Overview
description: Spring-physics interaction components with designed reduced-motion variants.
product: motion-primitives
since: 1.0.0
---

Install any primitive from the registry, the same way as [Lumen UI](/docs/lumen-ui/registry):

```bash
npx shadcn@latest add @lumira/segmented-control
```

Every component takes its timing from spring tokens (stiffness, damping, mass) and ships a reduced-motion variant that
replaces movement with an instant or opacity-only change.
