<Steps>
<Step>

### Download and install

Download the latest Docsmith release from your [Library](/account/library), then:

```bash
unzip docsmith-*.zip -d my-site && cd my-site
pnpm install
pnpm dev
```

</Step>
<Step>

### Replace the sample content

Edit MDX pages in `content/docs`. See [Editing content](/docs/docsmith/editing-content).

</Step>
<Step>

### Deploy

Follow [Deploy](/docs/docsmith/deploy).

</Step>
</Steps>

<Callout>Templates include a license key for support and the verified-owner Discord; activation is optional.</Callout>
