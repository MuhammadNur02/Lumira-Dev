SaaS Starter is a Next.js 16 application with organizations, subscription billing, transactional email and an admin console.
Every integration sits behind a small interface in `src/lib`, so swapping a provider is an adapter change.

<Steps>
<Step>

### Download the latest release

Open your [Library](/account/library), pick SaaS Starter and download the newest version. Verify the checksum shown next to the file.

</Step>
<Step>

### Install and configure

Follow [Installation](/docs/saas-starter/installation) and fill in the [environment variables](/docs/saas-starter/environment).

</Step>
<Step>

### Activate your license

Run `npx lumira@latest activate` once per project. See [Activating your license](/docs/saas-starter/activation).

</Step>
</Steps>

<Callout title="Requirements">Node.js 24 LTS, pnpm 10 or newer, and a PostgreSQL 16+ database.</Callout>
