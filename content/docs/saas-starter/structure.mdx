`src/server` holds domain services that pages and Server Actions call; nothing in `src/components` imports the database.
Every admin mutation goes through `withAudit()`, which writes an append-only audit entry.

## Data flow

Pages read through cached server functions tagged per entity. Mutations run in Server Actions, update the database in one
transaction, write side effects to an outbox table and call `updateTag()` so the next render reads fresh data.
