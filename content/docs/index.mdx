## Verifying a download

Every release in your Library lists its size and SHA-256 checksum (FR-DL-07). Compare it with your local file:

```bash
shasum -a 256 saas-starter-2.3.1.zip
```

On Windows PowerShell, use `Get-FileHash .\saas-starter-2.3.1.zip -Algorithm SHA256`.
